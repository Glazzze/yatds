## 0. 定位

### 0.1 视觉基调（D8 回填）

**选定 D8 形态 Ⅱ：独立清爽休闲风格。** 不复用课程 Pages 的文档式
导航与版式；网页是游戏本体，不是课程资料页。页面文件放
`Project/web/`，`file://` 直开可玩，不改动 [src/Pages/](../../../Pages/)
课程站点（T5.7 定于此）。

用户给定的风格约束逐条落到本文：

| 要求 | 落地 |
| --- | --- |
| 暖白/浅米背景，天空蓝辅助 | §1.1 色板：`#FBF8F2` 暖白 + `#EAF5FA` 天空蓝 |
| 珠子明亮易区分、不荧光不过饱和 | §3.2 八色调色板（中明度、低荧光），全部附字母标记 |
| 背景干净，少量浅色几何装饰 | §1.3 三处半透明几何形，无纹理、无深色底 |
| 圆形珠子、轻微高光、柔和阴影 | §3.2 球体 CSS 规格 |
| 细腻浅色线条/凹槽轨道 | §3.1 双层凹槽 + 浅色刻度 |
| 简洁可爱发射器 | §3.3 白色圆角底座 + 天蓝内环 |
| 短促轻盈粒子/缩放消除 | §6.1 消除 240 ms + 每球 ≤6 粒子 |
| 居中主游戏区、四周留白 | §2 布局：1232 px 主板，页面上下 16/14 px |
| 顶部关卡/分数/进度，角落暂停/音效 | §2.1 顶栏规格 |
| 圆角、统一尺寸间距的按钮 | §3.4 按钮 43 px 高 / 12 px 圆角 / 8 px 间距 |
| 电脑屏幕清晰可辨 | §2.4 ≥1021 px 为设计基准；球 48 px、正文 15 px |
| 避免深色石刻/复杂纹理/厚重装饰 | §1.4 "不做"清单（硬约束） |

### 0.2 三条设计原则

1. **游戏区优先**：所有装饰退到背景层；轨道、当前球、可选位置构成
   唯一视觉焦点，任何时刻都能一眼找到"下一步点哪里"。
2. **双通道编码**：颜色 + 球面字母（以及特殊符号）同时标识球种，
   色觉差异用户不依赖颜色也能游玩。
3. **规则零漂移**：网页是 C++ core 的独立 JS 复刻（D7=A），所有
   游戏状态变化必须能由 PROTOCOL 指令语义解释；装饰、动画、暂停、
   音效都不改变规则。双实现由 T5.6 交叉验证兜底。

## 1. 视觉系统

### 1.1 设计令牌（CSS 变量）

```css
:root {
  /* 背景与表面 */
  --bg-page:      #FBF8F2;   /* 暖白 */
  --bg-sky:       #EAF5FA;   /* 天空蓝浅晕（页面上缘） */
  --surface:      #FFFFFF;   /* 主板、弹窗 */
  --surface-warm: #F7F1E7;   /* 浅米色次级面 */
  --surface-blue: #F1F9FC;   /* 选中/提示底色 */

  /* 文字 */
  --ink:          #2F3E45;
  --ink-soft:     #5F7077;   /* 对 --bg-page 4.87:1 */
  --ink-faint:    #8D9A9F;   /* 仅用于非必要说明文字 */

  /* 线条与天空蓝 */
  --line:         #E6DED2;
  --line-strong:  #D6CCBD;
  --sky-100:      #EAF5FA;
  --sky-300:      #A9D8EA;
  --sky-500:      #6FB7D0;
  --sky-700:      #2E7F99;   /* 白字按钮 4.55:1 */
  --sky-ink:      #1F637B;   /* 深色文字 6.71:1 */

  /* 强调与状态 */
  --apricot:      #F3C27E;   /* 推荐位/进度高亮 */
  --apricot-ink:  #8A5A1F;
  --success:      #3F7F5D;   /* 白字 4.77:1 */
  --danger:       #B9524A;   /* 白字 4.81:1 */

  /* 阴影（只用柔和低透明，不用发光） */
  --shadow-soft:  0 10px 30px rgba(61, 90, 101, .08);
  --shadow-float: 0 16px 40px rgba(61, 90, 101, .12);
  --shadow-ball:  0 4px 8px rgba(47, 58, 63, .18),
                  inset 0 -3px 6px rgba(0, 0, 0, .10),
                  inset 0 2px 3px rgba(255, 255, 255, .55);

  /* 圆角与间距 */
  --r-sm: 10px; --r-md: 16px; --r-lg: 24px; --r-xl: 32px; --r-pill: 999px;
  --s-1: 4px; --s-2: 8px; --s-3: 12px; --s-4: 16px;
  --s-5: 24px; --s-6: 32px; --s-7: 48px;
}
```

### 1.2 字体与排版

- 字体栈（不引外部字体，保证 `file://` 离线与零依赖）：
  `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。
- 字号：页面标题 22/28，分数 32/36（`tabular-nums`），正文 15/22，
  辅助 13/18，按钮 14/20 600，球面字母 14/1 700。
- 中文按钮不加字距；数字与英文标签可加 `letter-spacing: .01em`。
- 字重只用 400 / 600 / 700 三档，避免页面上出现过多层级。

### 1.3 背景与装饰

- 页面底色：`--bg-page`，顶部叠一层 480 px 高的线性渐变
  `--bg-sky → transparent`，模拟晴空光晕。
- 三处固定装饰（`pointer-events: none; z-index: 0`）：
  1. 左上 220 px 半透明天蓝圆（不透明度 .35，外扩出屏）；
  2. 右下 160 px 浅杏色圆角方块（不透明度 .22，旋转 12°）；
  3. 轨道上空 5 个 6 px 浅蓝圆点组成的虚线弧（不透明度 .35）。
- 无纹理、无噪点、无石材/木纹/金属渐变；装饰不做高频动画，
  仅允许 20 s 周期 4 px 缓慢漂移，`prefers-reduced-motion` 时静止。
- 主板：`--surface`，1 px `--line` 边框，圆角 28 px，`--shadow-soft`；
  内部可有极淡的径向渐变（白 → `#FDFBF7`），不得干扰球体。

### 1.4 明确不做（对应"避免传统祖玛"）

- 深色石刻/丛林/神庙背景、厚重金色边框、浮雕与做旧纹理；
- 荧光色、纯饱和红绿、彩色发光（glow）、大面积白闪；
- 全屏烟花/爆炸、镜头震动、长时间粒子雨；
- 自动播放音乐、外部图片/字体/CDN 资源；
- 与规则无关的计时器、生命值、连击倒计时等隐性压力。

```text
│                                                                    │
│                     ·   ·   ·   （浅色点状装饰）                    │
│                                                                    │
│            ○  ○  ●  ●  ○  ○  ○  ○        ← 轨道凹槽               │
│            0  1  2  3  4  5  6  7        ← 悬停/键盘时显示位置标尺  │
│                       ╎                                            │
│                       ╎  ← 瞄准虚线（2 px 虚线，透明度 .35）          │
```

- 页面左右外边距至少 16 px；顶栏与主板同宽（`max-width: 1232px`）居中。
- 主板最小高度 620 px；轨道中心约在主板高度的 38%，发射器在 72%，
  控制条距底 24 px。所有区域共享 8 px 网格。
- 顶栏 78 px，两行：第一行标题/关卡/分数，第二行进度与角落按钮。
  窄屏时合并为单行可换行，不做横向滚动。
- 主板左右各留 26 px 安全边距；轨道超出时横向滚动（见 §3.1）。

### 2.2 区域规格

| 区域 | 尺寸/位置 | 内容 |
| --- | --- | --- |
| 顶栏 | 高 78，宽 1232 居中 | 游戏名、关卡选择、分数（含 +分浮动）、进度条与计数、历史/音效/暂停/帮助 |
| 游戏主板 | 1232×≥620，圆角 28 | 轨道、发射器、队列、控制条，全部居中 |
| 轨道区 | 宽 1180（左右 26 内边距），球 48 | 凹槽、球、插入位、标尺、提示高亮 |
| 发射器 | 94×94，轨道下方垂直居中 | 前球 59、底座、瞄准线起点 |
| 队列 | 发射器右侧 30 px | 前 6 颗（33 px）+ 计数 `+n` |
| 控制条 | 左下，按钮 43 高 | 撤销/提示/交换/倒退；右下显示轨道与队列剩余 |
| 历史抽屉 | 宽 405，右侧滑入 | 操作记录、快照预览 |
| 弹窗 | 440–748 宽 | 选关/自选/随机/暂停/结算/帮助 |

### 2.3 层叠顺序

`背景装饰 (0) < 主板 (1) < 弹窗遮罩 (20) < 弹窗 (21) < Toast (30)`。
历史预览高亮层属于主板内层；不使用 `!important` 堆层级。

### 2.4 响应式

| 断点 | 调整 |
| --- | --- |
| ≥1021 | 基准：球 48 px、间距 62 px、主板 1232 |
| 761–1020 | 主板随视口自适应（左右 16 px）；球与间距不变；HUD 重排为两行；按钮保留图标+文字 |
| ≤760 | 球 42、间距 62；主板内边距 14；位置标尺隐藏；控制条按钮隐藏 kbd 提示 |
| ≤560 | 球 36；队列球 29；HUD 三段重排；选关弹窗两列 |

触摸与鼠标共用事件模型；桌面点击目标最小 44×44（滑轨插入位 46×46），
窄屏球缩到 36 px 时靠 42/36 px 命中区与相邻空隙保持可点；悬停态仅在
`(hover: hover)` 下启用。

## 3. 组件规格

### 3.1 轨道（轨道 + 插入位）

- 用一条浅拱形 SVG 路径表示轨道（拱高 158 px），球心沿线等距排布；
  节距固定 62 px，轨道最小宽度为 `n × 62 + 106`，超出容器时横向滚动。
- 凹槽三层：
  - 外层 `stroke: #E9E1D4; width: 14; linecap: round`；
  - 内层 `stroke: #FBF8F2; width: 8`，形成浅槽；
  - 槽底 1 px `#FFFFFF` 高光，透明度 .6。
- 插入位是 **0…n** 共 n+1 个不可见按钮（桌面 46×46 命中区），视觉为
  6 px 空心圆点（`--sky-500` 半透明）：
  - `hover`：46 px 天蓝虚线圈 + 半透明幽灵球；
  - `selected` / 键盘焦点：46 px 实线 `--sky-500` 圈 + 外侧 4 px
    `--sky-100` 光晕（不是阴影发光）+ 下方 6 px 倒三角指示；
  - 悬停或键盘操作时，轨道下方显示位置数字（0 起，每 5 位标号，
    当前位置加粗）；离开 2 s 后淡出。
- 空轨道显示居中虚线槽 + 文案"轨道已清空"；此时仍保留 0 位插入点。
- 轨道球以绝对定位放置；每次状态变化只移动变化的节点（FLIP），
  不做整轨重建，避免长轨道闪烁。

### 3.2 球体

- 直径 48 px（响应式见 §2.4）；圆形，无描边或 1.5 px 半透明白
  内圈；高光在 30% 28% 处，柔和径向渐变；阴影见 `--shadow-ball`。
- 中心字母 16 px 700（特殊球用 18 px 符号），作为色觉辅助，不喧宾
  夺主；字母颜色按球色单独指定，全部 ≥4.5:1（下表实测值）。
- 普通球八色（COLORS 声明顺序映射；未声明不出现）：

| 符号 | 名称 | 球体主色 | 字母色 | 对比度 | 备注 |
| --- | --- | --- | --- | --- | --- |
| `R` | 红 | `#E8756B` | `#4A1F1B` | 4.78 | 珊瑚红，非纯红 |
| `G` | 绿 | `#76C293` | `#1D4630` | 5.03 | 草绿偏柔 |
| `B` | 蓝 | `#68A5DC` | `#14354D` | 4.86 | 天空蓝 |
| `Y` | 黄 | `#F2C75C` | `#5C4210` | 5.84 | 麦黄，非荧光 |
| `M` | 洋红 | `#D190BE` | `#4B2340` | 5.23 | 藕粉/莓色 |
| `C` | 青 | `#6CC8C6` | `#174845` | 5.23 | 薄荷青 |
| `W` | 白 | `#F3EEE3` | `#6B6254` | 5.19 | 加 1 px `#DCD3C4` 边 |
| `K` | 灰 | `#59646D` | `#FFFFFF` | 6.05 | 深灰，非纯黑 |

- 特殊球（仅出现在队列/新发射的球上）：
  - `*` 炸弹：`#55616B` 深灰球 + 奶油白四角星 `✦`，外加 1.5 px
    杏色环（`#F3C27E`，不发光）；悬停提示"炸弹：消除邻域至多 3 球"。
  - `?` 变色：柔和的薄荷→蜜桃对角渐变（`#CBE7D8 → #F7D9BE`）+ 深
    棕 `?`；未定色时不显示普通球色，定色瞬间渐变收拢为目标色
    （180 ms）。
- 球体只对 `transform` / `opacity` 做动画，避免布局抖动。

### 3.3 发射器与队列

- 发射器：94×94 白色圆形底座，内嵌 59 px 浅天蓝圆环
  （`--sky-300`）托住队首球；两侧各一枚 6 px 浅蓝圆点作装饰，
  整体像一只简洁的"弹珠托盘"，不做拟人表情。
- 队首球即当前待发射球，尺寸 59 px；队列其余球 33 px，向右排列，
  最多显示 6 颗，超出显示 `+n` 计数。队首与后续球之间留 7 px。
- 队列为空时，底座内显示空心虚线圈与文案"队列已空"（灰色）。
- `SWAP` 时前两颗沿 200 ms 小弧线交换；其余球不移动。
- 瞄准线：从发射器中心到当前选中插入位的 2 px 虚线
  （`--sky-500`，透明度 .35，圆点端点）；未选中时隐藏。
- 幽灵球：选中位显示 60% 透明的队首球；变色球在选色前显示渐变球。
- 发射器待机时以 4 s 周期上下浮动 2 px（`prefers-reduced-motion`
  时静止），幅度不得影响瞄准线端点。

### 3.4 顶栏 HUD

```text
[● 祖玛 · 彩球]   [关卡 03 · 连锁演示 ▾]      分数 000110  (+40)
轻 松 消 除  ·  已消除 6 / 9  [▓▓▓▓▓▓░░░]  [历史] [♪] [⏸] [?]
```

- 关卡选择：胶囊按钮，点开选关弹窗；显示两位关卡号 + 短标题。
- 分数：30 px 700，`tabular-nums`；得分时在右侧浮出 `+40`（600 ms
  上浮淡出），总分用 200 ms 数字滚动（减少运动时直接切换）。
- **进度定义**：`进度 = 1 − (当前轨道球数 + 当前队列球数) / 初始总球数`，
  即"已消除 / 初始总数"（初始总球数取**装载完成、初始 settle 之后**的
  轨道+队列球数；装载时的自动消除与 C++ 一致，不计分、不计入进度）。
  插入只是队列→轨道移动，不改变进度；消除增加进度，撤销回退进度。
  分母为 0 时显示满格并标"空局面"。
  进度条 8 px 高、圆角、`--sky-700` 填充；旁边文字"已消除 x / y"。
- 步数：在进度条下以 13 px 显示 `步数 3` 或 `步数 3 / 8`（有 LIMIT
  时显示上限，达到上限前 1 步变 `--apricot-ink` 提示）。
- 角落按钮（40×40 圆形，间隔 8）：
  - 历史（列表图标）→ 右侧抽屉；
  - 音效（喇叭/静音）→ 切换，默认关闭；
  - 暂停（双竖线）→ 暂停弹窗；
  - 帮助（问号）→ 规则与快捷键。
- 顶栏按钮均带 `aria-label` 与 tooltip；键盘焦点 3 px `--sky-ink` 外环。

### 3.5 控制按钮

| 按钮 | 图标 | 快捷键 | 可用条件 |
| --- | --- | --- | --- |
| 撤销 | 逆时针箭头 | `U` | 撤销栈非空（终局后仍可用） |
| 提示 | 星形/放大镜 | `H` | 队列非空且非终局 |
| 交换 | 双向箭头 | `S` | 队列 ≥2 |
| 倒退 | 水平双向箭头 | `R` | 轨道 ≥2 且非终局 |

- 高 43、圆角 12、左右内边距 13、图标 18 + 7 px 间距 + 文字 13/600；
  底色 `--surface-warm`，悬浮 `#F1E9DC`，按下下沉 1 px；主按钮不用
  高饱和实心色（本游戏没有单一主按钮）。
- 禁用：不透明度 .45、`cursor: not-allowed`，tooltip 说明原因
  （"队列不足两球""暂无可撤销操作"等）。

### 3.6 历史抽屉

```text
┌ 操作历史 ──────────────────── ✕ ┐
│ #7  发射 B → 3       +40  连锁×2 │
│ #6  提示 → 2           —        │
│ #5  撤销 #4           回滚       │
│ #4  交换               —        │
│ …                               │
│ 点击任一步仅查看当时局面          │
└─────────────────────────────────┘
```

- 只记录状态变化动作（SHOOT/SWAP/REVERSE/UNDO）；HINT 以灰色细行
  显示（无快照差），非法指令只走 Toast，不入历史。
- 每条记录保存**动作前后快照**（轨道、队列、分数、步数、状态）。
  撤销作为一条新记录追加（"撤销 #n"），之后若再执行新动作，则
  截断时间线中位于当前游标之后的记录（标准撤销分支语义）。
- 点击记录进入**只读历史预览**：主板以 120 ms 淡入显示该快照，
  顶部出现"历史 #5 · 只读 · Esc 返回"横幅，所有操作按钮禁用；
  上/下方向键切换前后记录。预览不修改引擎状态。D8 只要求"查看"，
  不提供从历史直接跳转（回退统一走撤销，保证与协议一致）。

### 3.7 弹窗

- 共用：遮罩 `rgba(47,62,69,.28)` + 4 px 背景模糊；卡片白底、圆角
  24、`--shadow-float`；入场 180 ms 上浮 8 px + 淡入；Esc / 点遮罩
  关闭（结算与暂停除外，避免误关闭）；焦点陷阱与 `aria-modal`。
- **选关**：16 个样例卡片（3 列），每卡显示编号、标题、一句话目标、
  最佳分（`localStorage`，仅本机）；点击载入。标题见 §8.4。
- **自选局面**：等宽字体 textarea，提示"粘贴 COLORS / TRACK / QUEUE
  （可选 LIMIT）"；只读取头部，后续指令行忽略并提示"仅装载局面"；
  实时校验，错误显示在字段下（颜色不在 COLORS、含特殊球、越界等）。
- **随机局面**：颜色数 2–6、轨道长度 3–30、队列长度 5–30、特殊球
  比例 0–20%、种子（默认随机）。`mulberry32` 确定性生成；生成轨道
  不得含初始 ≥3 同色段；底部显示种子并可复制；"换一个"保持面板，
  "载入"开始新局。
- **暂停**：继续 / 重新开始 / 选择关卡 / 音效开关；暂停时输入与动画
  停止，但引擎状态不变。`P` 或 Esc 继续。
- **结算**：标题（"轨道清空！"/"队列耗尽"/"步数用尽"）、分数、步数、
  最高连锁、消除球数；按钮"撤销最后一步"（回退到 PLAYING 并关闭
  结算）、"再玩一次"、"选择关卡"。胜利用 ≤60 片低饱和纸屑飘落
  1.2 s，失败只用淡入卡片，不用红色闪屏。
- **帮助**：规则摘要（三连、连锁、炸弹、变色、道具）、最短操作表、
  键盘快捷键；不链接外部资源。

### 3.8 Toast 与播报

- 位置：顶栏下方居中，距顶 88 px；白底、圆角 14、左侧 3 px 状态色、
  图标 + 一行文字，2.4 s 自动消失，可手动关闭。
- 错误格式：`无法发射：发射位置越界` + 第二行浅色建议
  （如"可选位置为 0–8"）。原因短语与 PROTOCOL §3.4 保持一致。
- 成功/中性提示：`已复制种子`、`没有可直接消除的位置`、`变色球不提示`。
- `aria-live="polite"` 独立播报区报告消除轮次与得分；错误用
  `role="alert"`，但同屏最多 1 条，防止刷屏。

## 4. 状态机与交互流程

### 4.1 页面状态

```text
READY ──悬停/方向键──→ AIM ──点击/空格──→ [CHAMELEON_PICK] ──选色──┐
  ↑                    │                                         │
  │                    └──点击/空格（普通/炸弹）──────────────────┤
  │                                                              ▼
  └──────────── ANIMATING（逻辑已结算，播放 ≤900 ms）──────────────┘
                                   │
                     ┌─────────────┼──────────────┐
                     ▼             ▼              ▼
                   READY        RESULT(WIN/LOSE)  PAUSED
                                   │
                                   └─撤销/再玩/选关─→ READY

READY ⇄ REVERSE_SELECT（R 进入，Esc 取消）
READY ⇄ HISTORY_PREVIEW（点击历史，Esc 返回）
任意非 RESULT 态 ⇄ DIALOG（选关/自选/随机/帮助/暂停）
```

- 动画期间只接受"跳过动画"（点击/空格/任意键），不接受第二条指令；
  跳过立即渲染终态，不改变引擎结果。
- 终局在最后一轮动画结束后 160 ms 弹出结算，避免盖住消除反馈。
- 撤销在结算弹窗中也可用；成功后回退到 PLAYING 并关闭结算。

### 4.2 发射流程

1. 指针悬停插入位 → 显示幽灵球、瞄准线、位置数字；键盘用 ←/→
   移动选中位（`1`/`0` 到两端，Home/End 保留为兼容别名）。载入局面后默认选中轨道中点
   `floor(n/2)`，避免初始落在容易误操作的末端。
2. 点击或 Enter/Space：
   - 普通球 → 立即执行 `shoot(pos)`；
   - 炸弹球 → 执行并播放邻域消散特效；
   - 变色球 → 在插入位上方弹出 8 色调色板（仅 COLORS 已声明色），
     点击色块或按 1–8 选色后执行 `shoot(pos, color)`；Esc 取消，状态
     与队列均不变；
   - 队列为空 / 终局 / 动画中 → 不进入发射流程，Toast 说明原因。
3. 控制器先让引擎结算（逻辑立即到终态），再按 `events` 播放动画；
   每个事件带本轮消除后的 `trackAfter`，渲染层逐轮替换球节点。
4. 播放完最后事件后刷新 HUD、历史、按钮可用性，返回 READY 或 RESULT。

### 4.3 道具与撤销

- **SWAP**：点击/`S` 立即交换前两球，200 ms 动画；不具备条件时按钮
  禁用。
- **HINT**：点击/`H` 调用 `hint()`；返回 `p ≥ 0` 时在 p 位显示杏色
  呼吸圈与"推荐"小标签（1.2 s）；返回 `-1` 时 Toast：
  - 队首为 `?`："变色球颜色自由，不提供提示"；
  - 否则："没有可直接消除的位置"。
  HINT 不计步、不入撤销栈，仅以灰色细行进入历史。
- **REVERSE**：点击/`R` 进入区间选择：在轨道上从 i 拖到 j（选中球
  轻微抬起 2 px、杏色描边），或键盘 ←/→ 移动起点、Shift+←/→ 扩展
  终点；Enter 确认，Esc 取消。有效区间要求 `0 ≤ i < j < n`（UI 比
  协议更严格，不允许单球无意义反转），确认后执行并播放翻转动画。
- **UNDO**：点击/`U` 调用 `undo()`；成功时 260 ms 淡入恢复快照并
  回滚分数/步数；失败（栈空）Toast"暂无可撤销操作"。

### 4.4 载入、暂停与音效

- 启动默认载入 `case03`（README 连锁示例，标题"连锁演示"）；首次
  显示一行轻提示"点击轨道空隙发射 · 空格发射 · H 提示"，首次操作后
  消失。也可从选关弹窗载入任意样例。
- 载入新关卡前，若当前已有操作且未终局，弹出确认"当前对局将结束"；
  载入后清空历史、最高连锁与撤销栈（属于新局面）。
- 暂停：停止动画与音效，锁定输入，遮罩下仍隐约可见局面；继续后
  从暂停点恢复（无计时器，因此无需补偿）。
- 音效默认关闭；开启后首次用户手势创建 `AudioContext`；状态记入
  `localStorage`。关闭时所有音效立即停止（无背景音乐，无循环音轨）。

### 4.5 错误与边界反馈

| 场景 | UI 行为 |
| --- | --- |
| 队列为空 | 发射器显示"队列已空"，插入位仍可聚焦但发射触发 Toast"待发射队列为空" |
| 终局后 | 结算弹窗；关闭后棋盘只读；仅撤销/选关/再来一局可用 |
| 位置越界 | UI 不产生越界位；如通过调试接口触发，Toast 显示协议原因 |
| 变色球未选色 | 调色板保持打开，不执行、不消耗球 |
| REVERSE 区间无效 | 确认按钮禁用，提示"请选择至少两颗球" |
| 撤销栈为空 | 按钮禁用；快捷键触发时 Toast 说明 |
| 自定义局面格式错误 | 字段下方红字定位（行号 + 原因），"载入"禁用 |
| 动画中重复操作 | 视为"跳过动画"，不缓存第二条指令 |

## 5. 与 C++ / PROTOCOL 的语义对应

### 5.1 操作映射

| 网页交互 | 网页 API | 协议等价 | 备注 |
| --- | --- | --- | --- |
| 点击空隙 / Enter | `shoot(pos)` | `SHOOT <pos>` | pos ∈ [0,n] |
| 选色后发射 | `shoot(pos, color)` | `SHOOT <pos> <color>` | 仅队首 `?` |
| 撤销 | `undo()` | `UNDO` | 终局后可回退 |
| 交换 | `swap()` | `SWAP` | 队列 ≥2 |
| 提示 | `hint()` | `HINT` | 不改状态、不计步 |
| 拖选/确认 | `reverse(i, j)` | `REVERSE <i> <j>` | UI 要求 i<j |
| 选关/自选 | `new Game(...)` | 头部三/四行 | 装载即 settle |
| 暂停/音效/历史/随机 | 网页专属 | 无 | 不进入输出契约 |

### 5.2 必须一致的不变量

- 消除轮次、每轮 `left/count/balls/points`、连锁倍率与结算顺序；
- 炸弹首轮邻域规则、变色球定色时机、非法指令零副作用；
- `UNDO` 的多区间逆序回填、分数/步数/队列回滚、终局回退；
- 胜负优先级（WIN 优先于 LOSE）、LIMIT 判定、装载时 settle；
- 错误短语与 PROTOCOL §3.4 完全一致（网页 Toast 复用原文）。

```text
      │                    │                    │
      │                    │               事件/快照
      │                    ▼                    ▼
      └── zuma --plain → protocol_io     view.js（DOM/SVG/动画）
                           │
                     PROTOCOL.md ←── 语义规范 ──→ C++ core
                           ▲

```

## 6. 动画与音效规范

### 6.1 动画

统一缓动：入场/落位 `cubic-bezier(.22,.61,.36,1)`（ease-out），
退场 `cubic-bezier(.4,0,1,1)`（ease-in）；只用 `transform` 与
`opacity`。

| 事件 | 时长 | 描述 | 减少运动时 |
| --- | --- | --- | --- |
| 球落位 | 220 ms | 从上方 16 px 落下 + 轻微挤压（1.06→1.0） | 直接出现 |
| 轨道让位 | 120 ms | 相邻球平移让出节距 | 直接重排 |
| 单轮消除 | 240 ms | 目标球先放大 1.12 再缩至 0，透明度 1→0；同时 6 个 3–5 px 同色粒子向外散开 420 ms（重力 300 px/s²） | 透明度 120 ms 淡出 |
| 连锁轮间隔 | 140 ms | 上一轮结束后 140 ms 开始下一轮，形成轻波次 | 0 ms |
| 消除涟漪 | 260 ms | 拼缝处 1 px 杏色环扩散到 36 px 后淡出，不闪白 | 不播放 |
| 分数浮动 | 600 ms | `+40` 上浮 20 px 淡出；总分同步滚动 | 直接更新 |
| SWAP | 200 ms | 两球沿半径 24 px 的弧线交换 | 直接交换 |
| REVERSE | 280 ms | 逐球 180° 水平翻面（`scaleX`），错峰 12 ms | 直接重排 |
| UNDO | 260 ms | 恢复快照淡入，被撤销的分数/步数向下滚动 | 直接切换 |
| HINT | 1200 ms | 杏色环 1→1.25 呼吸 2 次 + "推荐"标签 | 静态描边 |
| 结算卡片 | 360 ms | 上浮 12 px + 淡入 | 直接出现 |
| 胜利纸屑 | 1200 ms | ≤60 片低饱和纸屑，从顶部 40% 内飘落 | 不播放 |

- 同屏粒子上限 60；每颗被消球最多 6 粒；禁止全屏白闪与屏幕震动。
- 动画队列总时长上限 900 ms（超长连锁时缩短每轮），所有动画可被
  点击/空格跳过。
- `prefers-reduced-motion: reduce` 时全局时长 0，仅保留状态切换与
  必要的透明度变化；不使用闪烁。

### 6.2 音效

- 全部用 Web Audio 合成，无外部音频文件；默认音量 0.2，无音乐。
- 落位：210 Hz 正弦短音 60 ms；消除：520 Hz + 频率随连锁 +80 Hz，
  80 ms 衰减；交换：双音 280→340 Hz；撤销：340→260 Hz；
  错误：180 Hz 方波 90 ms（低音量，不刺耳）；胜利：C-E-G 三音上行。
- 同一时刻最多 3 个音效；暂停/静音立即断开；`M` 切换。
- 音效不参与规则，不因音效开关改变任何状态或计时。

## 7. 键盘与可访问性

### 7.1 快捷键

| 按键 | 作用 |
| --- | --- |
| `←` / `→` | 移动插入位（REVERSE 选择时为移动起点） |
| `Shift` + `←/→` | 插入位快移 5 格；REVERSE 时为扩展区间终点 |
| `1` / `0` | 插入位到 0 / n（`Home`/`End` 兼容别名） |
| `Enter` / `Space` | 在当前插入位发射；REVERSE 时确认区间 |
| `1`–`8` | 变色球调色板选色 |
| `U` / `H` / `S` / `R` | 撤销 / 提示 / 交换 / 倒退 |
| `V` | 打开/关闭历史抽屉 |
| `M` | 静音切换 |
| `P` | 暂停/继续 |
| `Esc` | 关闭弹窗/取消调色板/退出区间选择/历史预览/暂停；无上层状态时打开暂停 |
| `?` 或 `F1` | 帮助 |
| `Tab` / `Shift+Tab` | 焦点移动；可完整键盘游玩 |
| 历史预览中 `↑` / `↓` | 上一条/下一条历史快照 |

### 7.2 可访问性要求

- 对比度：正文/按钮 ≥4.5:1（§1.1 已给关键值）；球面字母 ≥4.5:1
  （§3.2 实测）；非文本控件边界 ≥3:1。
- 颜色不作为唯一信息：每球带字母，特殊球带符号，提示位带文字标签。
- 轨道以 `role="list"` 描述球序列；每个插入位是 `<button>`，`aria-label`
  如"在第 3 位插入（共 8 个位置）"；球节点 `aria-hidden`，整轨摘要
  通过 `aria-live` 播报。
- 焦点可见：3 px `--sky-ink` 外环 + 2 px 白色间隔，不得仅靠颜色变化。
- 所有功能可键盘完成（含 REVERSE 区间选择与历史浏览）；拖拽不是
  唯一路径。
- 弹窗焦点陷阱、Esc 关闭、返回焦点到触发按钮；Toast 使用
  `aria-live="polite"`，错误 `role="alert"` 且不连续轰炸。
- 尊重 `prefers-reduced-motion`；发声音效默认关闭；无自动播放。
- 页面语言 `lang="zh-CN"`；图标均有文字或 `aria-label`，纯装饰
  SVG `aria-hidden="true"`。

### 8.1 文件结构

```text

│   ├── protocol.js       # 样例/指令解析、Session、语义 token（UMD）
│   ├── controller.js     # 回合记录、历史、随机生成、输入文本导出
│   ├── view.js           # DOM/SVG 渲染、FLIP、动画队列、无障碍播报
│   ├── audio.js          # Web Audio 合成音效（开关）
│   ├── samples-data.js   # 由 make 从 inputs/ 生成的样例数据（生成物）
│   └── app.js            # 启动、状态机、键盘、弹窗、localStorage 胶水

├── gen_web_samples.js    # inputs/*.txt → samples-data.js（含标题表）

├── web_engine_test.js    # JS 引擎/协议/控制器单元测试

```

- **`file://` 约束**：Chrome 禁止 `file://` 下的 ES module 与 `fetch`，
  因此全部脚本为经典 `<script>`（非 `type="module"`），共享
  `window.Zuma` 命名空间；样例数据以 JS 字面量内嵌，不用 `fetch`。
- 不依赖任何外部 CDN、字体、图片或构建工具；阶段 5 的全部产物可
  直接双击 `index.html` 游玩。Node 只用于开发期交叉验证。
- `engine.js` / `protocol.js` / `controller.js` 均采用 UMD 包装：浏览器
  挂到 `window.Zuma`，Node 下 `module.exports`，使交叉验证与单元测试
  可直接 `require` 同一份源码。

### 8.2 引擎接口（语义对齐 C++ core）

```js
const game = new Zuma.Engine({ colors: "RGBY", track: "RRBB", queue: "BRB", limit: 0 });

game.trackNodes;   // [{id, color}, ...] 只读快照
game.queue;        // [{id, color}, ...] 队首在最左
game.score; game.moves; game.status; // "playing" | "win" | "lose" | "quit"
game.undoAvailable;
game.shoot(pos[, color]) -> { events, preSettle, insertedId, final }
game.swap()              -> { events, final }
game.reverse(i, j)       -> { events, preSettle, final }
game.hint()              -> -1 | pos
game.undo()              -> boolean
game.snapshot()          -> { track, queue, score, moves, status, limit }
game.initialTotal        -> number   // 进度分母：装载完成（含初始 settle）后的轨道+队列数
```

- `ElimEvent = { round, left, count, points, balls, trackAfter,
  removedIds }`；`removedIds` 供视图做逐球动画，不参与语义比对。
- 非法操作抛 `Zuma.ProtocolError`，`message` 使用 PROTOCOL §3.4 原文
  （如"发射位置越界""待发射队列为空"）；零副作用（先校验后出队）。
- 内部沿用与 C++ 一致的双向链表轨道 + 环形队列语义（JS 可用对象
  节点实现），保证事件坐标、撤销回填与 C++ 逐项一致；`id` 仅用于
  渲染定位。

### 8.3 控制器与视图

- **controller.js**：唯一允许调用引擎的层；每次动作生成
  `Turn { seq, kind, label, events, before, after, noMove, hintPos?,
  chainPeak, eliminated, scoreDelta }`，维护历史时间线与游标；
  解析自选局面与随机种子；把 `ProtocolError` 映射为 UI 提示。视图与
  音效不直接改引擎。
- **view.js**：从 `after` 快照渲染；按 `events` 逐轮播放（每轮拿到
  `trackAfter` 与 `removedIds`）；使用节点 id 做 FLIP 与消除定位；
  动画期间锁输入；提供 `prefers-reduced-motion` 快速路径。
- **app.js**：状态机（§4.1）、键盘、弹窗、localStorage（音效、
  最佳分）、初始化示例关卡。
- **audio.js**：暴露 `play("insert"|"pop"|"swap"|"undo"|"error"|
  "hint"|"win"|"lose"|"click")`，未开启或 `AudioContext` 不可用时静默失败。

### 8.5 双实现交叉验证（T5.6）

`tools/web_crosscheck.js`（Node ≥18）：

1. 遍历 `inputs/*.txt`，子进程运行 `./zuma --plain`（`NO_COLOR=1`）；
2. 解析协议输出为逐指令事件流（ELIM 五元组、TRACK、QUEUE、终局）；
3. 在 Node 中 `require("../web/assets/engine.js")`，以同一输入逐指令
   执行，得到结构相同的事件流与终态；
4. 逐项比对：接受/拒绝、错误短语、每轮 `round/left/count/points/balls`、
   每步轨道、终局 `status/score/moves`；
5. 任一不一致打印首个差异并退出 1；全过退出 0。
6. Makefile 提供 `make web-samples`、`make webcheck`、`make webtest`、
   `make webstatic`、`make webdom`、`make webverify`，以及可选的
   `make browsercheck`（Playwright + Chromium 真实渲染验收）；
   `web_engine_test.js` 另做 JS 侧规则/撤销/协议断言，
   `web_static_check.js`、`web_dom_smoke.js` 覆盖结构与 app/view 装配。

这是 D7=A 的漂移防线；网页交互本身（暂停、历史、随机）不参与比对。
