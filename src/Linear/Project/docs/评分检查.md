## 原问题的处理结果

1. 炸弹HINT：所有位置首轮为min(3,n+1)，同分最左返回0；两端首尾/单球回归通过。
2. QUIT：C++退出输入循环，JS会话退出后不再解析；核心引擎也拒绝QUIT后撤销。
   WIN/LOSE后HINT回显报错；装载终局可HELP，UNDO无记录时报空栈。
3. 成本：局部链操作与完整事件区分，完整消除为O(n+d+rn)，最坏O(n²)；
   撤销反复定位计入O(d+(r+1)n)；JS区间反转改为一次定位后沿next收集。
4. 静态输入与参考：严格执行原协议边界，修正旧单色测试；reference_game.hpp
   以顺序字符串/完整快照实现独立参考，已比较十万局每步事件、状态与撤销。
5. 规模与规则：记录100/500/1000初始球、2000队列球的耗时和快照规模；
   REVERSE的两条独立连锁各从第1轮计分，总分60的例子已明确写入协议并测试。

原来没有独立参考引擎的random_diff版本应称为随机属性测试；本轮新增参考后
才是参考差分。有限随机测试不等于形式化正确性证明。
