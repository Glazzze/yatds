    怎么玩

    规则与 C++ 命令行版本完全一致

    基本规则

    从待发射队列取最左的球，插入轨道任意空隙。连续 3 颗及以上同色球会消除，拼缝再次形成三连时继续连锁，连锁倍率 10 → 20 → 40…。

    轨道清空即胜利；队列耗尽仍有余球、或步数达到上限即失败。撤销可回退终局。

    特殊球与道具

    • ✦ 炸弹：消除落点邻域至多 3 球，无视颜色。
    • ? 变色：发射时选择一种已声明颜色。
    • 交换：交换队首两球。 提示：高亮最佳插入位。
    • 倒退：反转一段轨道，拼出新的三连。
