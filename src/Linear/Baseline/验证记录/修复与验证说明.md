# 提交版源码修复与验证说明

日期：2026-10-28。本说明对应当前提交版源码；原两份实验报告 PDF 保留历史实验过程和截图，未重新生成。PDF 与各 Baseline 说明中的旧耗时、性能倍数、测试数量，应结合本说明及本轮数据阅读，不能直接作为当前版本实测结果。

## 修改内容

1. **Vector 自身引用安全**：基础版与扩展版的 `push_back` 在扩容前保存参数；`insert` 在扩容或后移前保存参数；扩展版 `resize` 与 `assign` 在改变存储前保存填充值。覆盖参数引用自身元素的调用，修复读取已释放内存和插入取错值的问题。
2. **链表模板定义公开**：baseline1 和 baseline2 公共链表的实现放入同目录 `linked_list.tpp`，由 `linked_list.hpp` 包含。保留 `.cpp` 为兼容入口，移除仅支持 int/double/char 的显式实例化限制。新增 `std::string` 与自定义无默认构造类型测试。
3. **构建与失败传播**：StackAndQueue 的 check/oracle/asan/space 在失败时返回非零；增加 build、unit、regression 入口，perf 自动构建所需程序。Makefile 跟踪头文件/模板文件依赖，避免头文件修改后仍运行旧程序。List 的两套基础链表测试也会在断言失败时返回非零。
4. **回归与性能测量**：新增自身引用、模板泛型、构建失败传播、统计工具和性能数据采集器测试。访问/遍历计时移除建表与下标生成，校验和与编译器屏障保留操作的可观察结果。使用 steady_clock；List 独立基准预热后交替比较顺序，记录 24 次样本；StackAndQueue 保存 30 次独立运行的原始数据。总体标准差的实现与文字口径统一。
5. **统计与空间口径**：Welch 双侧 p 值直接用尾概率计算，避免 `1-CDF` 相消为 0；零方差不适用时返回 NaN，非法样本量被拒绝。空间工具使用 Linux `/proc/self/statm` 或 macOS `task_info`，测量当前 RSS 的前后增量，非历史峰值 RSS；读取失败会报错。

## 新测量结果的解释

- List 的独立访问基准只计访问本身；命令式 `test` 中的简化 PERF 是包含建表的冒烟测量，两者不能混为同一个指标。
- 在本轮 `n=1000000` 的随机访问测试中，自实现 Vector 与 `std::vector` 的均值接近，统计输出未显示显著差异。不能延续旧报告中“自实现随机访问更快”的结论。
- 在头部插入 `m=10000` 的测试中，自实现 Vector 的均值明显高于标准库；本轮数据不支持“相同复杂度就具有相同常数开销”。具体均值、离散程度和显著性见本轮日志及原始数据。
- 数组与链表的随机访问采用相同固定种子的 2000 个下标；CSV 同时记录容器长度 n 与计时操作数 ops。建表移出计时后，访问成本的差距与旧口径下的倍数不同，不能直接横向套用旧倍数。
- RSS 是进程层面的采样增量，包含分配器与操作系统影响，不等于容器精确申请的字节数，也不用于单独证明某项缓存或分支机制。

## 仍有的边界

- 主要为确定性样例和回归测试，尚未加入系统的随机/模糊测试。
- 未固定 CPU 频率或隔离用户机器的其他负载；List 的重复样本来自同一进程，StackAndQueue 为多次进程运行。统计显著不能替代对实际影响和实验条件的判断。
- 自实现容器不提供完整 STL 能力；抛异常元素类型下的资源回收与强异常保证未做专项完善。
- VectorQueue 出队仅移动 head，下层历史元素不自动压缩回收，长期运行的空间占用仍有优化余地。
- 原 PDF 的 Prompt 截图仍为原实验过程证据，本轮未补作聊天截图；当前修复证据以源码、自动化回归和日志为准。
