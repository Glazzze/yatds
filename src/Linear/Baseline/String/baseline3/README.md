## 核心设计

### 1. 遗传密码与 6 条翻译序列

标准遗传密码表以静态 `unordered_map<string, char>` 表示 64 个密码子；终止密码子 `TAA / TAG / TGA` 翻译为 `'*'`，非法密码子（含长度不为 3）返回 `'X'`。

对 DNA 正向链按阅读框 $f \in \{0,1,2\}$ 从下标 $f$ 起每 3 个碱基翻译一个氨基酸，不足 3 个的尾部丢弃；对反向互补链（先反转，再 `A↔T`、`C↔G`）同样做 3 个阅读框。共 6 条蛋白质序列参与 KMP。

### 2. KMP 匹配与第一行 `pi`

对目标蛋白 $P$（长度 $m$）求前缀函数 `pi[j] = P[0..j]` 的最长真前缀 / 后缀公共长度，第一行输出该数组（证明使用了线性匹配算法）。在 6 条翻译序列上运行 KMP，**允许重叠**：每次命中后令 `matched = pi[matched-1]` 继续扫描，而不是清零。

### 3. 坐标映射回原序列（1-based 闭区间）

设原 DNA 长度 $n$、蛋白长度 $m$、匹配块长 $3m$；翻译序列第 $a$ 个氨基酸（0-based）对应本链上的起点 `start = f + 3a`。

**正向链**（`strand = '+'`，frame 输出 $f+1$）：

$$
L = start + 1 = f + 3a + 1,\qquad R = start + 3m = f + 3a + 3m
$$

**反向互补链**（`strand = '-'`）：rc 下标 $k$ 对应原序列下标 $n-1-k$，区间的**两个端点都要翻转**：

$$
L = n - (start + 3m) + 1,\qquad R = n - start
$$

**官方样例核验**（$S$ 长度 $n=23$，$P=MA$，$m=2$，块长 $3m=6$；`start` 均为 0-based）：

| 链 | frame 索引 / 输出 | 翻译序列中的命中 | `start` | $L$ | $R$ | 输出 |
| :--- | :---: | :--- | ---: | ---: | ---: | :--- |
| `+` | 1 / 2 | frame 1 第 0 个氨基酸 | 1 | 2 | 7 | `2 7 + 2` |
| `-` | 1 / 2 | rc frame 1 第 2 个氨基酸 | 7 | $23-13+1=11$ | $23-7=16$ | `11 16 - 2` |
| `+` | 2 / 3 | frame 2 第 5 个氨基酸 | 17 | 18 | 23 | `18 23 + 3` |

反向链一行代入映射公式：$L = n-(start+3m)+1 = 23-(7+6)+1 = 11$，$R = n-start = 23-7 = 16$，两个端点都翻转后才与原序列坐标一致。

### 4. 区间查询：前缀和

所有匹配片段长度恒为 $3m$，因此“右端点 $R \le r$”等价于“左端点 $L \le r - 3m + 1$”。令

$$
\mathrm{prefix}[x] = \#\{\text{匹配}: L \le x\}
$$

则查询 $[l,r]$ 的答案为

$$
\mathrm{prefix}\big[\min(r-3m+1,\ n)\big] - \mathrm{prefix}[l-1]
$$

（下标先夹到 $[1,n]$；区间容不下任何片段时差值自然为 0）。预处理 $O(n+K)$，单次查询 $O(1)$，总体 $O(n + m + q)$。

**排序**：匹配按 $L$ 升序；$L$ 相同时 `'+'` 先于 `'-'`；再按 frame 升序。`answerQueries` 只依赖左端点，排序不影响计数，但保证输出稳定。

## 命令式测试的 I/O 语义

输入：第 1 行 DNA `S`，第 2 行目标蛋白 `P`，第 3 行查询数 `q`，随后 `q` 行 `l r`。

输出：

1. 第 1 行：`P` 的前缀函数 `pi`（空格分隔）；
2. 第 2 行：匹配总数 $K$；
3. 接下来 $K$ 行：`L R strand frame`（1-based 闭区间）；
4. 最后 $q$ 行：每个查询的答案。

本任务输出**完全确定，无 PERF 行**，`test` 对功能行逐字符精确比对。

边界语义：$P$ 为空、$P$ 长于任一阅读框、无匹配时 $K=0$；查询 $l<1$、$r>n$ 时对端点夹取到 $[1,n]$，$l>r$ 返回 0；小写碱基统一转大写；非 `ACGT` 字符按非法密码子处理为 `X`。

### 随机差分验证

`tools/oracle.py` 是**独立实现**的暴力 oracle：前缀函数按定义 $O(m^2)$ 计算，6 条翻译序列上的匹配逐位置暴力比较（不用 KMP），坐标映射与区间统计各自重写。对随机小规模 DNA / 蛋白 / 查询做差分：

```sh
python3 tools/oracle.py 300 20261110
# 随机差分验证通过：300 轮，全部一致（种子 20261110）
```

300 轮随机用例覆盖了正 / 反链、不同阅读框、重叠匹配、区间边界与随机查询，全部与 `test` 输出一致。

## 复杂度

| 阶段 | 时间 | 空间 |
| :--- | :--- | :--- |
| 翻译 6 条序列 | $O(n)$ | $O(n)$（可逐条处理，峰值 $O(n)$） |
| 前缀函数 + 6 次 KMP | $O(m)$ + $O(n + m)$ | $O(m)$ |
| 前缀和预处理 | $O(n + K)$ | $O(n)$ |
| 每次查询 | $O(1)$ | — |
| **总计** | $O(n + m + q)$ | $O(n + m)$ |

其中 $K \le 6 \cdot (n/3 - m + 1)$ 为匹配数。题目要求 $q \le 2\times10^5$、$n$ 可达 $10^6$ 量级，$O(n + m + q)$ 满足要求；若每次查询重扫匹配集合则为 $O(qK)$，在大数据下不可接受。

## 已知边界与取舍

- `P` 不含 `'*'`；翻译序列中的 `'*'` 作为普通字符参与 KMP。
- 反向互补的坐标映射把**两个端点都翻转**（不能只翻转起点），这是本任务最容易出错的地方；官方样例与 300 轮随机差分都覆盖了反向链。
- 查询端点越界时做夹取而非报错，$l>r$ 直接返回 0；与“完整包含”的语义一致。
- 实现保留 `dna_search.cpp` 中的 `START/END` 标注与中文注释；未调用任何语言自带的字符串查找函数，匹配全部由自实现 KMP 完成。
