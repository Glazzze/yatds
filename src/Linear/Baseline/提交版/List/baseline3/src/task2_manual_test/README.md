# 手动构造测试程序（可视化验证）

`main_manual.cpp` 编译为 `manual`。按课程 README 任务内容第 2 条要求，在测试代码中**手动构造**三类边界链表，并分步打印命令行可视化输出、对每一步断言，验证三个挑战的正确性：

1. **存在环的单条测试链表**：构造 `1→2→3→4→5` 且尾结点指回下标 2（值 3）；打印环入口值 → 解环后链表，断言入口值为 3、解环后为 `1 2 3 4 5`。
2. **不相交的两条独立无环链表**：`1 2 3` 与 `4 5`；断言交汇点为 `NONE`。
3. **相交的两条无环链表**：前缀 `10 20` / `30` 共享尾部 `7 8 9`；断言交汇点值为 7，反转公共部分后 `LIST_A = 10 20 9 8 7`、`LIST_B = 30 9 8 7`。

`main` 返回非零表示存在失败断言，便于脚本判断。

## 验证

```sh
make unit      # 打印分步可视化输出 + 断言；全部 [PASS]
make asan      # 同一程序在 ASan/LSan 下运行，验证零泄漏、无双重释放
```

> 注：可视化含环链表时用限步遍历（而非 `to_vector`），避免沿环无限打印。
